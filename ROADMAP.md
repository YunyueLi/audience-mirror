# Roadmap

Audience Mirror follows a public, evidence-first iteration path. Dates are
targets, not promises; completed capabilities must remain reproducible.

## v0.1 — Public Alpha

- deterministic local baseline;
- evidence-linked Timeline and Trace contracts;
- tiered Persona execution with explicit scale accounting;
- Media reference environment and self-contained report;
- public evidence register and validation protocol.

## v0.2 — Real multimodal run（local alpha implemented）

- [x] model-independent Environment Contract and Media adapter;
- [x] public／authorized local video ingestion, frame evidence and audio extraction;
- [x] native full-video provider contract and Gemini adapter;
- [x] sequential model-backed experience contract with call and budget caps;
- [x] Human Anchor calibration diagnostics and interactive workbench;
- [ ] execute a public-video native provider run and publish reproducible non-sensitive artifacts;
- [ ] add ASR, OCR, diarization and agentic high-FPS verification;
- [ ] add a first non-Media Environment adapter example.

## v0.3 — Human comparison

- preregistered public-material study;
- blinded Agent-to-human problem and A/B comparison;
- repeatability, disagreement, abstention, cost, and latency reporting;
- calibration scopes that never hide uncalibrated outputs.

## Later candidates

- Web／App and game Environment Packs;
- social interaction experiments with Foreworld／GAIA or other runtimes;
- private deployment controls, deletion receipts, and enterprise audit trails.

Feature requests are welcome when they include a concrete experiment, an
evidence path, and a validation proposal.
