# Audience Mirror v0.1.0-alpha

Audience Mirror is an open multimodal population experimentation platform for
simulating how heterogeneous people experience, judge, choose, and influence
each other before reality.

This first public alpha ships a deterministic Media reference environment. It
generates a synthetic Persona universe, runs separate Deep Trace and Broad
Sweep layers, creates a zero-LLM population projection, and renders an
evidence-linked local report. No API key, model call, private data, or external
Persona dataset is required.

## Try it

```bash
git clone https://github.com/YunyueLi/audience-mirror.git
cd audience-mirror
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
audience-mirror demo
```

Open `artifacts/public-demo/report.html` in a browser.

## What this release proves

- experiment contracts can preserve scale provenance and run fingerprints;
- individual reactions can be linked to Timeline evidence through immutable
  hash-chained Trace events;
- a report can separate Deep Trace, Sweep, Projection, and future Human data;
- the public baseline is deterministic, locally runnable, and zero-cost.

## What it does not prove

- simulated users represent a real population;
- 10,000 projected records are 10,000 independently run agents;
- model outputs predict attention, preference, purchase, revenue, or virality;
- the current Media runtime generalizes to every Environment.
