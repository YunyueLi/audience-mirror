# Audience Mirror v0.2.0-alpha.3

Audience Mirror 的可核查视频实验、公开视频 Benchmark 与真人盲测准备开发者预览。

## 这次可以直接体验什么

- 粘贴已获授权的公开视频链接或上传本地文件，在本机解析真实比例视频、证据帧、音轨与人工字幕；
- 在默认浅色、可切换深色的视频主舞台中浏览时间轴、事件证据、个体 Trace、实验进度与校准状态；
- 打开 `/components.html` 审查共享 Token、基础组件、证据业务组件、反馈状态、键盘行为和 reduced-motion；
- 直接打开 GitHub Pages 只读公开体验；它使用同一工作台与组件系统，展示合成实验且不上传、不调用模型；
- 使用 31 题《Sintel》公开开发集验证视觉、片尾 OCR、对白、时间定位、顺序和跨事件理解；
- 比较同模型同条件重复运行，分别查看回答状态、逐字、参考得分和证据区间漂移；
- 从一个或两个冻结 Timeline 生成匿名、结果盲法、A/B 反平衡且密钥隔离的真人研究包；
- 导入与实验版本严格对齐的 Human Anchors，检查问题召回、时间点召回、同名代理量误差和 A/B 方向。

## 已验证结果

- 65 项自动化测试通过；
- 无字幕与人工字幕语义 Timeline 各完成三次 GPT-5.6 Sol／xhigh 运行：宏平均 62.4% 与 81.7%；
- 一次 GPT-5.6 Terra／xhigh 无字幕敏感性探针为 64.5%，不并入 Sol 稳定性统计；
- 12 槽公开 Sintel 单版本盲测包已生成，完成真人数明确为 0；
- 真实 16:9、9:16、1:1、4:3 与 2.39:1 视频均按 `contain` 呈现，移动页面零横向溢出；
- 独立 Wheel 从源码外安装后包含工作台、Component Lab、Benchmark、稳定性与盲测 Schema，并能运行 Demo、Benchmark 校验与盲测包生成。

## 不能据此声称什么

- 三次模型运行不是三位真人；Agent 数和计划参与者槽位都不构成真人样本；
- 《Sintel》题集仍是单维护者草案，尚未完成第二位独立标注，不能发布稳定模型排名；
- 固定帧和语义 Timeline 路径未把原视频或音轨发送给 Reasoner，不等于原生完整视频理解；
- 字幕条件的增量同时伴随视觉题下降，需要分模态消融；
- 注意、情绪、理解、购买与分享仍是未经真人校准的预测代理量；
- 当前服务默认仅监听回环地址，不是可直接暴露公网的多租户 SaaS。

## 数据与许可边界

Release 不包含媒体、证据帧、字幕文件、密钥、Cookie、真人数据、模型权重或第三方 Persona 数据集。《Sintel》只登记公开来源、内容哈希、题目、时间窗和 CC BY 3.0 署名。MiroFish／MatrAIx／Foreworld 等第三方项目代码没有并入本仓库。

安装与运行见仓库 README；方法边界见 `docs/12-public-video-benchmark.md`、`docs/14-sintel-stability-and-caption-baseline-2026-08-21.md` 与 `docs/15-blind-study-packet.md`。
