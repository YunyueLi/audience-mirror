# Audience Mirror v0.2.0-alpha.1

Audience Mirror 的首个真实视频纵向切片与开放合同预览。

## 本版包含

- 真实本地 MP4 解码、证据帧、场景差分和单声道 16 kHz WAV；
- 原视频／音轨回放、时间片 seek 和可下钻证据工作台；
- 通用 Environment Contract 与 Future-blind Media Adapter；
- 确定性及模型驱动的 Persona 顺序体验 Runtime；
- Gemini 原生整片视频 Adapter、逐次授权和敏感分级门禁；
- Human Anchor 版本对齐、撤回排除和校准诊断；
- 10k Persona Pool、Deep Persona、Trace Event 与 Human Participant 分账；
- 20 项自动化测试与可构建 Python Wheel。

## 使用边界

这是开发者预览，不是经过真人验证的人群预测产品。默认 Demo 不调用远程模型，所有注意、情绪、理解和购买输出在真人校准前均为预测代理量。10k Persona Pool 不等于 10k 次完整体验，也不等于 10k 位真人。

Gemini 和 Claude Code Adapter 已实现，但本版没有随 Release 发布真实远端模型结果、密钥、媒体、真人数据、模型权重或第三方 Persona 数据集。

安装与运行方式见仓库 [README](../../README.md)，实现状态见[本地发布候选状态](../11-release-candidate-status-2026-08-20.md)。
