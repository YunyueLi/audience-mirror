# Audience Mirror v0.2.0-alpha.2

Audience Mirror 的链接优先真实视频实验与证据工作台开发者预览。

## 这次可以直接体验什么

- 粘贴有权处理的公开视频直链，或 YouTube、Bilibili、抖音页面链接；本地文件仍是备用入口；
- 在本机完成视频下载、音画合并、解码、证据帧、人工字幕和可校验 Timeline；
- 用固定帧视觉 Provider 或可选的原生整片 Provider 建立语义事件；
- 让 Persona 按时间顺序经历事件，并保留过去记忆、行动、成本和哈希链 Trace；
- 在固定视口三栏工作台中从群体代理量下钻到时间点、素材证据和单个 Persona；
- 导入与实验版本对齐的 Human Anchor，检查 Top 问题召回、时间点召回和 A/B 方向；
- 关闭并重新启动服务后恢复本地实验与深链接。

## 已验证的工程闭环

- 48 项自动化测试；
- Qwen 公共 MP4 直链与 Blender Foundation YouTube 页面真实导入；
- 《Sintel》888 秒全片的 148 张本地证据帧、12 个语义事件和 1 Persona × 12 Event 顺序体验；
- 桌面与 390 px 移动端真实浏览器交互、视频原始比例、时间片 seek 和四个 Inspector 视图；
- 从源码目录外安装 Wheel 后，Schema 校验和零 Key Demo 可运行。

这些结果证明的是工程合同和证据下钻链路，不是虚拟用户对真人、票房、收入或传播的预测准确率。

## 安全与数据边界

- 默认只监听 `127.0.0.1`，当前版本不是可直接暴露到公网的多用户服务；
- URL 导入必须确认素材权利，平台登录、Cookie、地区和版权限制不会被绕过；
- 远程模型处理需逐次确认，`confidential` 与 `restricted` 素材默认拒绝公有路由；
- Release 不含媒体、密钥、Cookie、真人数据、模型权重或第三方 Persona 数据集；
- 所有注意、情绪、理解、购买和分享输出，在同任务真人校准前均为预测代理量。
