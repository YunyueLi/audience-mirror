# Sintel 重复运行稳定性与人工字幕增量基线

日期：2026-08-21

Benchmark：`sintel-public-dev-v0.1`

模型：GPT-5.6 Sol／xhigh
状态：开发结果；题集仍是单维护者草案

## 结论

同一无字幕语义 Timeline 重复三次后，宏平均为 62.4%，单次范围为 58.1%—64.5%。模型是否回答的一致率为 95.7%，真正导致参考得分变化的题目为 2/31；开放文本逐字一致率只有 59.6%，说明同义改写很多，不能把字符串差异全部解释成认知不稳定。

加入平台人工字幕的三次对照宏平均为 81.7%，范围 80.6%—83.9%，比无字幕三次均值高 19.4 个百分点。对白均值从 0% 升到 86.7%，时间顺序从 33.3% 升到 100%，跨事件从 55.6% 升到 100%；视觉事实则从 96.7% 降到 80%。重复运行缩小了单次随机波动的影响，但两组仍是不同 Timeline 条件，不能把所有差值都归因于字幕本身。

三次模型运行仍然是三个技术重复，`human_sample_size` 明确为 0。它们不构成三位受访者，更不支持现实人群比例。

同一无字幕 Timeline 另做了一次 GPT-5.6 Terra／xhigh 敏感性对照，宏平均为 64.5%，与 Sol 三次范围重叠。单次跨模型结果只能说明当前失败模式没有立刻翻转，不能据此断言模型等价。

## 1. 无字幕同条件三次重复

三次运行均满足：

- Provider：`openai-codex-cli`；
- 模型：`gpt-5.6-sol`，推理强度 `xhigh`；
- 策略：`semantic_timeline_text`；
- Timeline 指纹：`1cebaf9e3cf01aa3c0d12c9cdde5f16cdf210537c0692317966ecec573b97884`；
- 12 个语义事件；
- 不发送原视频、音轨或证据帧；
- 不提供片名、页面标题或参考答案；
- 每次一次结构化模型调用，31/31 prediction 返回。

| 运行 | 模型时延 | 宏平均 | 回答 | 弃答 |
| --- | ---: | ---: | ---: | ---: |
| Run 1 | 50,306 ms | 64.5% | 21 | 10 |
| Run 2 | 51,186 ms | 58.1% | 23 | 8 |
| Run 3 | 51,191 ms | 64.5% | 21 | 10 |
| **汇总** | **152,683 ms** | **均值 62.4%** | — | **均值 9.33** |

宏平均总体标准差为 3.04 个百分点。分项中，OCR、对白、时间定位与时间顺序的参考得分三次相同；视觉事实有一次从 100% 降到 90%，跨事件有一次从 66.7% 降到 33.3%。

### 稳定性口径

| 指标 | 结果 | 解读 |
| --- | ---: | --- |
| 回答／弃答状态两两一致率 | 95.7% | 两道对白顺序题在不同运行中“弃答／作答”变化 |
| 开放答案逐字归一化一致率 | 59.6% | 对同一事实存在大量同义改写，不能单独当错误率 |
| 参考得分发生变化 | 2/31 | `visual-08-reaching-pose`、`cross-02-environment-shift` |
| 时间答案两两 IoU | 100% | 三次都选用相同语义事件边界 |
| 证据区间两两 IoU | 100% | 验证引用可复现；不等于从原视频独立定位稳定 |
| 广义不稳定题 | 11/31 | 包含九道只发生文字改写的题与两道回答状态变化题 |

因此发布时应同时展示逐字差异、参考得分差异和证据漂移，不能只报一个“稳定率”。

## 2. 人工字幕同条件三次重复

字幕对照使用同一 12 事件结构，并附加公开页面的人工中文字幕；融合后 Timeline 指纹为 `708a4563b1e9ffdde12af9fef0cdd2f4b90dc14ff685c652a5060b0d35343dee`。模型仍未看到原视频或音轨。三次运行均返回 31/31 道答案，没有弃答。

| 运行 | 模型时延 | 宏平均 | 回答 | 弃答 |
| --- | ---: | ---: | ---: | ---: |
| Run 1 | 56,114 ms | 80.6% | 31 | 0 |
| Run 2 | 61,253 ms | 83.9% | 31 | 0 |
| Run 3 | 57,431 ms | 80.6% | 31 | 0 |
| **汇总** | **174,798 ms** | **均值 81.7%** | — | **0** |

宏平均总体标准差为 1.52 个百分点。三次的回答／弃答状态一致率为 100%；开放答案逐字归一化一致率为 65.4%；参考得分有 3/31 题变化，分别是 `visual-06-blurred-shape`、`visual-09-scaled-head` 与 `dialogue-04-name`。时间答案和证据区间的两两 IoU 都是 100%，仍主要反映输入事件边界固定。

| 类别 | 无字幕三次均值 | 人工字幕三次均值 | 差值 |
| --- | ---: | ---: | ---: |
| 视觉事实 | 96.7% | 80.0% | -16.7 pp |
| 片尾 OCR | 100.0% | 100.0% | 0.0 pp |
| 对白 | 0.0% | 86.7% | +86.7 pp |
| 时间定位 | 40.0% | 40.0% | 0.0 pp |
| 时间顺序 | 33.3% | 100.0% | +66.7 pp |
| 跨事件 | 55.6% | 100.0% | +44.4 pp |
| **全部** | **62.4%** | **81.7%** | **+19.4 pp** |

字幕三次的证据命中率均为 74.2%，平均最佳 IoU 均为 0.676。低于无字幕三次的 100%／0.975，不代表字幕让定位更差：字幕运行对所有题都作答并提交证据，无字幕运行的弃答没有进入证据分母，两者分母不同。

视觉事实三次都停在 80%，说明它不只是一次波动。更可能的解释包括：更长的字幕文本挤占了事实层注意、融合后的事件表达改变了回答表述，或这两项视觉参考本来就超出固定 12 事件的可靠覆盖。需要用原始证据帧／原生视频条件和分模态消融区分这些原因。

## 3. 跨模型单次敏感性

GPT-5.6 Terra／xhigh 在完全相同的无字幕 Timeline、Prompt、策略和可见模态下运行一次：49,451 ms，回答 20 题，弃答 11 题，宏平均 64.5%。分项为视觉 100%、OCR 100%、对白 0%、时间定位 40%、时间顺序 33.3%、跨事件 66.7%。

它与 Sol Run 1 的分项和总分相同，但具体开放文本及弃答题并不完全相同。该结果是跨模型敏感性探针，不进入任何一组重复稳定性统计；至少需要各模型多次重复，才能比较模型间方差与模型内方差。

## 4. 新增稳定性命令

```bash
audience-mirror benchmark stability \
  --benchmark fixtures/benchmarks/sintel-public-dev-v0.1.json \
  --predictions run-1.json run-2.json run-3.json \
  --output stability-report.json
```

命令会拒绝把不同 Provider、模型、版本、策略、Timeline 指纹、视频可见性或音频可见性的运行混在一起。报告固定包含：

- 技术重复次数和 `human_sample_size: 0`；
- 总分均值、范围和总体标准差；
- 回答／弃答状态一致率；
- 非时间答案逐字一致率；
- 时间答案两两 IoU；
- 证据区间两两 IoU；
- 参考得分变化、状态变化和文字改写三类题目清单。

## 5. 限制

1. 题集尚未经过第二位真人独立标注，不能发布稳定模型排名。
2. Sol 三次无字幕运行只测同一模型重复性；Terra 只有一次，尚不能估计跨模型鲁棒性。
3. 开放文本完全一致会低估同义表达稳定性；当前同时报告参考得分变化，后续可增加固定同义词归一化，但不使用另一个 LLM 充当不可审计裁判。
4. 证据区间高度稳定主要由输入事件边界决定，不是原生整片定位成绩。
5. 本轮 CLI 未返回 token 与价格，不能生成可靠美元成本；模型调用数和墙钟时延已完整记录。

## 6. 下一步

1. 将 Terra 条件也重复三次，再比较模型内方差与模型间差异；
2. 接入原生整片 Provider，与固定帧和主动局部复核比较；
3. 对字幕融合做消融：对白题仅看字幕、视觉题仅看视觉事件、跨事件题看融合输入；
4. 第二位真人完成独立标注与裁决后冻结公开开发集；
5. 事实层达到预注册门槛后，再把同一 Timeline 交给少量 Deep Persona，并将 Persona 反应稳定性与事实准确性分开报告。
