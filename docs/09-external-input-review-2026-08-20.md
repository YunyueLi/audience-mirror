# 新增外部输入复核

版本：External Input Review v0.2
日期：2026-08-20
状态：Reviewed

## 1. 输入与边界

本轮复核了三类输入：

1. 用户提供的七张私聊截图；
2. 用户提供的三篇微信公众号文章链接；
3. 最初发起本项目的数字分身任务记录与其新一轮脱敏复核结论。

截图只用于提炼 C／H 级方向性信号；姓名、私聊原文、未公开案例和合作关系未进入仓库。三篇公开文章的完整正文后由用户提供；本文只保留摘要和证据判断，不复制原文。

## 2. 三篇公开文章的证据处理

| 输入 | 复核后可用的信号 | 一级来源校验 | 对产品的净修正 |
| --- | --- | --- | --- |
| 神经美学访谈 | 审美体验可部分测量，但生理信号不取代文化背景、个人经历和主观评价 | 清华大学的公开报道确认真实演出中的 EEG／眼动／生理采集与自然场景、文化适配挑战；iScience 2025 和 European Journal of Neuroscience 2024 支持连续参与的可测性，也限定了解释范围 | 保留生理为 Human Anchor；新增接受语境条件；不建立“脑同步＝共同喜爱”的总分 |
| MatrAIx 传播报道 | 开源项目的规模叙事有强声量价值，Persona 基础设施可复用 | 论文、定版代码、Quickstart 和数据卡显示：83 亿是记录宇宙，论文实际为 18,189 个 Trial；91.5% 是 Persona adherence；跨底模结果波动很大 | 继续复用 Persona／Cohort／Trial 合同；Pool、Deep、Sweep、Projection 严格分层；开源传播不改变有效性门槛 |
| 公开电影现象评论 | 戏谑、社交货币、身份参与、对工业化精致感的反弹可能使“观看一个内容”变成“参加一个事件” | 文章的具体票房数字与七层归因未经本项目独立验证；Science 2006 MusicLab 真人实验显示，社会影响越强，文化市场成功越不平等且越不可预测 | 新增 Participation Mode 与 Context Sensitivity；把盲测内容反应、预设社会语境和发布后观测分开；明确不从内容独立分析承诺预测文化黑天鹅 |

其中最重要的反直觉读法是：真实剧场的神经与生理测量不会让产品变成“审美脑电仪”；社会语境的强作用也不会让产品变成“爆款预测器”。两者共同要求产品记录观看发生的条件，并在这个条件内解释反应。

## 3. 总体复核结论

**总体技术方向不需推翻，但前一版把首个验证场景误写成了项目边界。新增输入应扩展 Audience Mirror 的通用机制和外部叙事，而不是把它限制成影视审片工具。**

| 问题 | 复核前 | 新增输入后 | 决策 |
| --- | --- | --- | --- |
| 平台与首个环境 | Audience Mirror 曾被近似写成影视／IP 工具 | 潜在合作需求使 Media 成为强入口；MiroFish 与 MatrAIx 表明宽平台叙事可以和具体首发环境共存 | Audience Mirror 保持通用平台定位；Media 只作为首个验证环境 |
| 核心输出 | 理解、情绪代理量、版本差异与行为意向 | 需要补足文化参照、身份／社群语境、戏谑、反抗和传播语言 | 增加 Interpretive Divergence，但只做带证据的定性假设，不做“文化共鸣分” |
| 数据壁垒 | Persona 池、Timeline、Trace 与 Human Anchor | 垂直数据结构和经验证历史轨迹比 Persona 数量更关键 | 将内容结构、脱敏画像、行为／运营语境、真人编码和历史结果做成版本化数据合同 |
| 生理数据 | 可选 Human Anchor，不进首轮实时设备接入 | 潜在合作方拥有相邻经验，但生理信号不足以解释文化突围 | 保持为可选校准通道；与自报、访谈、行为和文化编码分开报告 |
| 接受语境 | 尚未成为独立实验变量 | 现场／共同观看会改变参与；社会线索又会带来路径依赖和不可预测性 | 每次实验冻结 Reception Context、信息截止时间与语境种子；独立盲测和语境场景结果分开报告 |
| 产品承诺 | 发布前方向性证据 | 群体情绪和文化语境增加不确定性 | 仍不承诺票房、播放量、收入或真实市场比例 |

## 4. 与数字分身的交叉检查

数字分身的脱敏复核支持 Media 作为首个切口，但不能据此推导 Audience Mirror 应被永久收窄。本轮重新区分“平台边界”和“交付顺序”：

- 首个验证环境应选择长周期、高成本叙事内容的观看体验评测；
- MVP 的主产物是过程证据、关键情节反应、分群差异、流失／传播机制和可执行修改，不是市场预测总分；
- 优质数据结构应先于大规模 Agent 仿真；
- 眼动和生理信号是辅助参照，文化、戏谑、反抗和群体传播语境需要独立的真人编码与验证；
- 游戏、Web／App、商品与社会情境是后续 Environment；首版不同时实现，但公共合同不能把它们排除在外。

## 5. 对 MVP 的具体影响

### 立即纳入文档

1. Audience Mirror 顶层定位保持多环境人群实验；Media PRD 明确“观看体验／内容叙事”，不把该垂直措辞上升为平台限制。
2. Persona Panel 增加有来源的 `interpretive_context`，包括媒介经验、文化参照和社群语言；禁止由人口标签自动补齐。
3. Trace 与报告区分 Observed Content、Simulated Response、Interpretive Context 和 Behavioral Decision。
4. Human Anchor 按自报、访谈编码、行为、眼动和生理信号分别记录和验证。
5. Experiment Manifest 冻结 Reception Context、信息截止时间、结果盲法状态和社会语境种子。
6. 报告将内容独立反应、Context-conditioned Response 和发布后实际观测分开；Participation Mode 只用带证据的多标签，不做总分。

### 不在本轮仓促修改

- `human-anchor.schema.json` 已支持 `eye_tracking` 与 `physiological` 工具类型，不因私聊方向性信号新增未经定义的设备字段。
- `trace.schema.json` 的 `extensions` 可在原型中承载定性 Interpretive Context；只有私有试点冻结编码表后，才考虑把它升级为一级字段。
- 公开 Demo 仍优先《Sintel》顺序体验与同源预告 A/B；文化解释层在有真人开放回答的第二素材或私有试点中验证。
- 不把已知市场结果的公开案例直接做成“预测 Demo”。若做回溯实验，必须使用事前可得资料、独立信息截止时间和结果泄漏审查。

## 6. 下一个高价值验证问题

在私有试点中选一个已有真人访谈、且真人对同一片段存在多种解读的内容。封存真人编码后，比较 Agent 能否：

1. 找到同一时点的主要解读与少数解读；
2. 给出对应素材证据和文化参照；
3. 保留组内分歧，而不是将人群压成一个“共鸣分”；
4. 在换模型、去标题和重复运行时保持或明确放弃该结论。

这个问题比“群体共鸣指数是多少”更难，但更接近新增输入指向的真实产品价值。
