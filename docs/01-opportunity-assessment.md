# 机会判断：Audience Mirror 平台与首个 Media Environment

状态：Research Baseline v0.4
日期：2026-08-20

## 1. 结论

**建议以“宽平台命题、窄首轮证明”推进。** 多模态人群模拟具备开源传播、跨行业合作和产品化空间，但通用有效性尚未成立。工程上先做一个 2—4 周、能与真人反馈盲测的 Media Environment；架构、Schema 和对外定位保持对 Web／App、游戏与社会情境开放。

平台命题是：

> 在现实发生前，让不同背景、偏好、能力与关系的人群进入一个多模态或交互环境，观察他们如何体验、评价、选择并相互影响；实验全程可回放、可复现，并用真人资料校准。

Media Environment 的首个可验证命题是：

> 在真人试映之前，让一组有稳定背景、偏好和记忆的目标受众按时间顺序体验未发布内容；所有结论都能回到具体时点、画面、声音、个体状态和版本差异，并用少量真人数据持续校准。

平台价值来自“提前暴露决策风险”“探索人群差异”和“缩短现实实验周期”。首个垂直用内容版本验证这些能力；Agent 数量、拟人台词和神谕式总分本身不构成价值。

当前信心拆分如下：

| 判断 | 信心 | 依据 |
| --- | --- | --- |
| 长周期内容存在发布前研究预算 | 高 | 真人试映、影视预测、广告前测和游戏用研均已有成熟产品 |
| 保密、速度和多版本迭代是明确痛点 | 高 | 脱敏一手访谈；aiScreeningRoom、iScreeningRoom 等产品也把这些问题写成核心卖点 |
| 模型已能解析 8—20 分钟内容并生成带时间点的反馈 | 中高 | 商用视频模型、长视频论文与相邻产品已证明可运行 |
| 未校准 Agent 能代表目标人群分布 | 低 | 多项研究显示方差压平、效应夸大、子群误描和拒绝行为不足 |
| “顺序体验 Trace + 真人校准”愿意被单独付费 | 中低 | 差异在公开竞品中并未完全消失，但尚无本项目自己的采购验证 |
| 可由此可靠预测票房、留存或收入 | 很低 | 研究证据不支持；不作为产品承诺 |

## 2. 真实问题是什么

平台级问题是：真实世界中的人群实验通常昂贵、缓慢、低频，而且往往发生在重大投入之后；现有 Persona 问卷或社会模拟又很难证明个体真正经历了完整环境。内容、产品、游戏和公共情境虽然观察对象不同，却共享五个基础问题：异质人群、顺序暴露、长期记忆、行为选择、群体影响。

Media Environment 是目前证据最强、入口最明确、也最适合四周内闭环的首个场景。其具体问题是内容决策的反馈时钟与生产时钟错位：

问题不只是“调研贵”，而是内容决策的反馈时钟与生产时钟错位：

1. 电影、剧集、IP 演出和大型游戏内容投入早、周期长，真正目标用户往往到粗剪、封闭测试或软启动阶段才首次完整体验。
2. 这时核心结构、资源配置和发行窗口已经很难改变；一次错误不只是损失素材成本，还可能损失档期、口碑和后续 IP 生命周期。
3. 真人研究需要招募、排期、保密、观看和编码，适合关键节点验证，却难以覆盖每天出现的新剪辑、新包装和新营销版本。
4. 现有 AI 内容分析常给“节奏、情绪、受众、票房”等汇总，创作者很难核对某条结论来自哪一秒、哪种模态、哪位受众以及怎样的记忆变化。
5. 合成用户工具能快速访谈 Persona，但多数流程是“读概念／摘要后回答问题”，没有证明角色真的按顺序经历了整段内容。

因此，首个 Job-to-be-Done 是：

> 当内容仍可修改时，快速找出值得进入真人验证的段落、人群和版本，并把问题定位到可复查证据。

## 3. 为什么现在成立

### 3.1 采购类别与竞争投入已经出现

[Largo Content Insights](https://home.largo.io/largo-content-insights/) 已公开销售脚本／视频分析、情绪弧、数字孪生焦点组和影视表现预测；其[公开套餐](https://home.largo.io/business-model/)覆盖每年 2,500—60,000 美元，并把模拟、合成与真实受众放进同一产品线。标价和产品页不能证明实际成交、续费或本项目目标客户的预算，只能证明这一采购类别和厂商投入已经出现。

[aiScreeningRoom](https://aiscreeningroom.com/) 在 2026 年公开进入邀请制 Beta，直接主张观看整部真实影片、多次独立运行、逐分钟参与度、时间戳证据和剪辑版本复测。它还公开了[验证摘要](https://aiscreeningroom.com/validation/)：校准语料包含 35,666 份真人问卷和 42,936 条逐时反应；AI 对 8 部封存影片的人类 Panel 评分平均误差为 0.286（1—5 分尺度），排序相关为 0.762。这个样本极小且属于厂商自证，但已经否定了“完整 AI 试映尚无人做”的假设。

### 3.2 技术跨过了“可跑”门槛

主流视频模型已经支持音频、视觉和时间戳联合输入。以 [Gemini 视频文档](https://ai.google.dev/gemini-api/docs/video-understanding) 为例，1M 上下文可处理约一小时默认分辨率视频；同时，默认 1 FPS 会漏掉快速动作和切镜。结论很清楚：原型能跑，可靠产品仍需要镜头切分、自适应采样、分层记忆和证据回查。

[LongVideoBench](https://arxiv.org/abs/2407.15754) 与 [Video-MME-v2](https://arxiv.org/abs/2604.05015) 都显示，长视频中的分散信息聚合、时间建模和复杂推理仍显著落后于真人。[InfiniBench](https://aclanthology.org/2025.emnlp-main.984/) 更直接覆盖平均 53 分钟的电影／剧集：最佳受测模型在 grounding 技能上只有 47.1%，且只给标题等元数据时也会借预训练知识猜中部分答案。机会来自工程编排与验证方法，不来自假设基础模型已经自然“像人一样看完”；原型还必须加入去片名／去标题对照。

### 3.3 合成受众研究给出了可用边界

[1,052 人生成式个体模拟研究](https://arxiv.org/abs/2411.10109) 显示，基于两小时访谈、结构化调查或两者结合的 Agent，在保留 GSS 题目上达到真人两周自我复测一致性的 82%—86%；只给人口统计时为 74%。这支持“用真实个体资料做更好的方向性模拟”，不支持凭空生成一千个角色。

相反，[156 个心理与管理实验复现](https://arxiv.org/abs/2409.00128) 发现，主效应方向复现约 73%—81%，交互效应约 46%—63%，效应量却常为真人的 2—3 倍，零效应也经常被误报为显著。[ACL 2026 的校准研究](https://aclanthology.org/2026.acl-long.498/) 进一步发现，纯合成估计可产生 24%—86% 偏差，加入真人回答做统计校正后才将特定任务偏差压到 5%以内。

[Nature Machine Intelligence 的 3,200 人研究](https://www.nature.com/articles/s42256-025-00986-z) 还显示，四类模型会误描并压平 16 类身份群体，调高温度也不能消除组内差异损失；[真实销售对话的 2026 预印本](https://arxiv.org/abs/2606.20708) 则发现模拟客户显著少表达拒绝、更多停留在犹豫状态。这要求产品单独验证组内方差、拒绝、跳过、放弃和不购买，不能只看平均分与措辞是否像人。

产品含义是：真人校准应进入数据模型、工作流和报告首屏，不能留到“以后有数据再做”。

### 3.4 真实观看情境可测，但社会结果不能由内容单独预测

[清华大学的公开报道](https://www.tsinghua.edu.cn/info/1182/117553.htm)显示，真实演出情境下的脑电、眼动和生理采集已经进入实地研究，研究者同时承认自然环境信噪比和文化适配难题。[iScience 2025 的现场舞蹈实验](https://www.sciencedirect.com/science/article/pii/S2589004225011836)也发现，现场共同观看与更高的连续参与和 δ 频段跨脑同步相关。但论文明确提醒：这类同步可能反映对共同刺激的相似加工与共同注意，不必然等于共享情感。

另一边，[Science 2006 MusicLab 实验](https://pubmed.ncbi.nlm.nih.gov/16469928/)让 14,341 名真人在有或无他人选择线索的人工音乐市场中做决策：社会影响越强，成功越不平等、越不可预测，质量只能部分决定结果。

产品含义是：接受语境必须进入实验设计，但不能变成新的预测口号。主结果应来自独立盲测；共同观看、戏谑口碑、争议或社群语言作为明示 Context Scenario，只报告条件敏感性。对已知市场结果的案例，只有锁定事前资料和信息截止时间，才能用于回溯验证。

### 3.5 项目具备罕见的场景入口

脱敏一手资料包含两个独立信号：

- 影视业务决策者明确描述了长制作周期、短发布窗口、真人预映泄密和逐段分群反馈需求，同时提醒当时技术尚未准备好，应先验证模拟与评测能力。
- 潜在合作方将问题进一步收窄为“内容叙事／观看体验的受众反应”，而非通用商品消费决策；其自述的既往研究还包含眼动、脑电／生理感知与内容叙事数据。

新增一手交流还提出两个对产品边界有价值的判断：第一，群体模拟的核心资产更可能是“内容结构—脱敏画像—行为／运营语境—历史结果”的垂直数据合同，不是再做一个 Persona 生成器；第二，生理反应不足以解释亚文化、戏谑、身份认同、反抗与群体情绪驱动的内容突围。这些仍是 C／H 级方向性输入，需通过真人编码和项目对照验证。

团队具备游戏发行、内容商业化、用户反馈自动化和 AI 产品试点经验。它使“游戏第二阶段”具备业务判断基础，也使产品能围绕真实购买链路、版本迭代和跨地区人群设计，而不是停在泛化 Persona 演示。

这些是一手方向性证据，不能外推市场规模、数据可用性或签约意愿。

### 3.6 开源基础设施显著降低了进入成本

2026 年 7 月底开放的 [MatrAIx](https://github.com/MatrAIx-ai/MatrAIx-Persona-8B) 已提供大规模 Persona Schema／Coreset、Cohort、Task／Trial／Verifier、四类交互环境和报告骨架；[TinyTroupe](https://github.com/microsoft/TinyTroupe)、[genagents](https://github.com/StanfordHCI/genagents)、[OASIS](https://github.com/camel-ai/oasis) 与 [Concordia](https://github.com/google-deepmind/concordia) 分别覆盖小型 Persona 实验、真人资料驱动个体、百万 Agent 社媒和社会环境。这使小团队可以在现有栈上新增 Media Environment，而无需扩招、购买 GPU 或重写通用引擎。

这个变化同时抬高了产品门槛：Persona 生成、Cohort 与基础 Agent Runner 不再构成充分差异。商业价值必须来自连续多模态体验、可审计 Trace、真人校准、私密内容工作流和实际决策闭环。

独立创作者虽有痛点，但客单价和校准数据不足，不适合作为第一付费客户。政策、金融和医疗等高风险预测也不进入首版。

### 4.2 采购成立的必要条件

客户至少需要同时具备：

1. 一个仍可修改、且错误代价明显高于测试成本的决策；
2. 两个版本或一组清楚的研究问题；
3. 可定义的目标受众；
4. 素材处理授权和安全边界；
5. 既有真人资料，或愿意配合一个小型真人盲测。

若客户只想要“便宜、好看的 AI 报告”，项目会落入低壁垒内容分析市场。

## 6. 项目补哪一个空位

公开市场没有留下宽阔空白，只存在一个需要实验确认的交叉空位：

### 6.1 可审计的顺序体验

Agent 按实际暴露顺序更新理解、预期、情绪、角色好感、记忆和行为；后面的反应只能使用之前看过的信息。它解决“看过摘要后编一段合理意见”的伪体验问题。

### 6.2 个体、语境与群体分开保存

先保存每位 Agent 在独立盲测下的判断，再用隔离 Session 做显式接受语境敏感性，最后才进行小组讨论或传播。报告同时显示语境注入前后、讨论前后的观点变化和影响来源，避免把社会线索、群体从众误写成内容本身效果或独立样本。

### 6.3 结论到多模态证据的闭环

任何问题卡、曲线峰值或版本差异都能回到：

- 素材版本与时间段；
- 画面、对白、音乐、音效或 UI 证据；
- Agent 看到了什么；
- 此前记住和误解了什么；
- 状态怎样变化；
- 哪些 Agent 不同意。

### 6.4 真人校准与误差作为一等公民

产品区分“内容观察”“模拟反应”“真实测量”，并持续显示：

- 当前任务是否有真人校准；
- 校准样本来自何种人群；
- 方向一致性、误差与重复运行波动；
- 哪些指标只能用于生成假设；
- 哪些分群没有足够证据。

### 6.5 中国内容与私有数据工作流

中国已有广告前测与通用虚拟调研产品，说明本地数据和部署非常重要。机会在于结合中文叙事、IP 熟悉度、平台使用习惯、消费能力和本地真人资料，同时提供 VPC／私有部署、短留存和访问审计。

## 7. 多模态与群体智能各自贡献什么

| 能力 | 解决的问题 | 没有它会怎样 |
| --- | --- | --- |
| 多模态时间轴 | 识别具体画面、对白、角色、音乐、UI、动作和事件，并保持时间与版本对齐 | 只能评剧本摘要或字幕，无法解释视觉、声音和剪辑造成的反应 |
| 顺序记忆 | 保证 Agent 只基于已经暴露的信息形成理解、预期和误解 | 模型会用结局倒推动机，产生事后聪明 |
| Audience Panel | 表达目标分层、差异、约束和已有真实数据 | 得到一个平均、礼貌、趋同的“通用观众” |
| 群体互动 | 探索讨论、口碑、社交影响和观点迁移 | 只能看到独立反应，无法研究传播；但首版仍应把它后置 |
| 真人校准 | 纠正平均值、方差、拒绝／离开和子群偏差 | 输出只具备语言可信感，没有决策可信度 |

## 9. 主要风险与停止条件

### 9.1 产品风险

- Largo 或 aiScreeningRoom 的真实 Demo 已经提供同等级分层个体 Trace、透明校准和中国部署，且客户没有明显切换动机。
- 买方只关心一个可转发总分，不愿查看证据或提供真人数据，导致差异无法转化为价值。
- 影视客户采购周期过长，早期试点无法获得可用素材和基准。

### 9.2 科学风险

- 顺序运行相对 one-shot 基线没有稳定提升 Top 问题召回或 A/B 方向一致性。
- 不同底模、Prompt 或重复运行频繁翻转结论。
- Persona 只改变表达风格，不改变可验证的判断和行为。
- 对“拒绝、放弃、不买”等负向行为持续系统性低估。
- 系统无法区分素材反应与社会语境注入，或依赖已知市场结果生成事后合理解释。

### 9.3 工程与安全风险

- 逐段多模态调用使成本和耗时接近真人快速研究，失去迭代优势。
- 未发布媒体必须进入不满足客户安全要求的第三方服务。
- 模型供应商升级导致结果不可复现，且项目未保留足够指纹和缓存。

### 9.4 Go／Iterate／Stop

- **Go**：达到验证计划的全部必须门槛，并有内容决策者实际使用 Trace。
- **Iterate once**：高于下列停止线、低于 Go 线，且失败能归因于一个预注册的可修正原因；只允许一次方法修订，随后用新素材或封存数据重测。
- **Stop／Pivot**：触发任一停止线，或一次修订后仍未达到 Go。

停止线：

1. 方向覆盖达到预注册门槛后，两个独立素材的 A/B 方向一致性仍低于 60%，且一次允许的修订无明显改善；
2. Human Top-5 Recall 连续低于 50%；
3. 五次重复运行的 Top-5 问题 Jaccard 中位数低于 0.5，或关键版本结论翻转超过 20%；
4. 无法获得任何同素材真人基准；
5. 三个合格买方均认为证据 Trace 不影响决策；
6. 安全要求使可用模型和成本无法满足两周内迭代。

若停止，仍可保留多模态时间轴与报告层，转为“真人研究加速工具”，用 AI 做素材解析、逐时编码和洞察回链。

## 10. 最终机会判断

值得做的是一轮严格的产品实验，不是先验成立的大平台。

最佳切入点应进一步收窄为：

> 8—20 分钟的影视／IP 叙事片段与同源营销版本，在真人研究前完成可审计的分群顺序体验，并先用小型真人盲测发现偏差，再在封存研究中校准。

它避开 15 秒广告前测的数据壁垒，也暂不与完整长片评分仪器正面竞争；同时足以验证长程记忆、角色理解、版本差异和人群分层。只有连续两轮实验通过验证门槛，才进入完整粗剪、群体传播和游戏交互。
